# audit/ — the per-turn audit record

`turns.jsonl` in this directory is the deliverable audit trail: one JSONL record per
agent turn (eval runs and interface chats write the same format), appended by
`agent/audit.py`. The directory is gitignored **except this README** — records are
runtime evidence, regenerated by running the agent; the schema is code-documented.

## Schema

Authoritative definition: the module docstring of `agent/audit.py` and
`architecture.md` §6. Summary per record:

| Field | Meaning |
|---|---|
| `turn_id` | `"{conversation_id}:turn_{seq:03d}"`, globally unique (collisions get a uuid suffix) |
| `timestamp_utc` | ISO-8601 Zulu time the turn started |
| `identity` | `user_id`, `role`, `region` — server-resolved; `"(all regions)"` when the role has no regional assignment |
| `resolved_scope` | `column_tiers`, `row_scope`, `case_notes`, `aggregate_only`, `tables_denied` — the authority actually enforced |
| `question` | the user's question, verbatim |
| `tool_calls[]` | per tool call: `tool`, `sql_requested` (model's original), `sql_executed` (**rewritten** statement actually run; for floor refusals the stopped rewritten statement; `""` when nothing was generated/executed), `rewrites_applied` (non-null array), `refusal` (`{category, detail}` or null), `rows_returned`, `latency_ms`, `params` (scope bindings to replay `sql_executed`), `reason` (decline reason / clarify question) |
| `answer_kind` | `answer` \| `clarify` \| `decline` \| `error` |
| `redactions_applied` | output suppressions (floor group/cell suppression, row-cap truncation) |
| `tokens` | `input` / `output` token counts for the turn |
| `total_latency_ms` | wall time of the whole turn |

Records are metadata only — never row values — so the audit file cannot itself become
a disclosure channel.

## Using the file

```bash
# The regulator's one-liner: what did the agent see, on whose authority? (per identity,
# with a zero-null schema check, unique-turn_id check, and p50/p95/token/dollar metrics)
.venv/bin/python -m agent.audit [path-to-turns.jsonl]
```

In Python: `audit.load_records(path)`, `audit.check_records(records)`,
`audit.per_identity_report(records)`, `audit.metrics(records)`,
`audit.records_for_conversation(conversation_id, path)`. The per-turn record is also
carried on `AgentResult.audit` (the interface layer returns it from `POST /chat`).

## Dollar accounting

Pricing step (documented in `agent/audit.py` and the NOTES.md cost section):
**$1.25 / MTok input, $10.00 / MTok output** for gpt-5.6-terra.
`dollars = tokens.input/1e6 * 1.25 + tokens.output/1e6 * 10.00`.
